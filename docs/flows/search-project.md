# Flow: search the project's source (Ctrl+Shift+F find bar)

1. **Trigger** - press `Ctrl+Shift+F` / `Cmd+Shift+F` anywhere (even from another input), or use **Search ▾ → Search project** in the top toolbar (menu calls `CanvasUiState.openFindBar("content")`). `Ctrl+F` is left to the browser; `Ctrl+P` opens the same bar in go-to-file mode (`docs/flows/go-to-file.md`).
2. **Entry point** - `ProjectSearch` (`features/graph_canvas/Private/project_search/`), always mounted by `GraphCanvas` so its window `keydown` listener pre-exists; the bar renders top-center (drops below the diff overlay bar when a diff is active).
3. **Step-by-step sequence**
   1. Typing updates local component state only; `useDebouncedSearch` waits 300 ms (queries under 2 chars clear results with no IPC; a sequence counter drops stale out-of-order responses).
   2. `GraphSessionStore.searchProjectSources(query)` picks the scope - the full graph, or `filterTestModules(graph)` while **Hide tests** is on - and forwards the module paths to `AnalysisClient.searchModuleSources(root, query, paths)`.
   3. Tauri command `search_module_sources` -> `backend_shell` facade -> `search::search_sources` (Rust): case-insensitive per-line substring scan over each module's working-tree source; one result per matching file using its first matching line; stops at 500 files (`truncated: true`); skips unreadable files. The mock client mirrors this over fixture sources (`search-fixture-sources.ts`).
   4. The bar shows `N of M` (`0 of M` before the first jump, `M+` when truncated, `No results`).
   5. `Enter`/Down next, `Shift+Enter`/Up previous (wrap-around via `stepIndex`): the bar calls `moveGuard.begin()` then `store.focusOn(module.id)` to select the module, expand its ancestors, and center it. Search navigation does not open or raise document previews; an already-open preview survives the programmatic pan. However, any preview the user opens **while the bar has a query** (context menu, symbol click) opens with its in-frame find bar pre-filled with that query (see `docs/flows/find-in-preview.md`).
   6. `Esc`/Close closes and clears; a store `phase-changed` (project reload/failure) does the same.
4. **Reads** - store `graph`, `root`, `hideTests`; module sources on disk (backend).
5. **Writes** - the live query is mirrored into `CanvasUiState.setFindQuery` (non-emitting — no re-renders; cleared on close) so newly opened preview frames can seed their find bar; navigation performs the usual `selectedId`, selection history, and focus sequence via `focusOn`.
6. **Side effects** - viewport pan per jump; possible async re-layout when collapsed ancestors expand.
7. **Files to inspect** - `project_search/{ProjectSearch,ProjectSearchBar}.tsx`, `use-debounced-search.ts`, `match-stepper.ts`, `SearchMenu.tsx`, `canvas-ui-state.ts`, `graph-session-store.ts` (`searchProjectSources`), `analysis-client.ts`, `src-tauri/src/search/mod.rs`, `tauri_api/mod.rs`.
8. **Common failure modes** - sources edited after analysis make line numbers drift (stale until the project reloads, same staleness class as review-note anchors); toggling **Hide tests** after a search leaves stale results whose hidden modules select but do not center (`FocusNode` no-op); broad queries clip at 500 matches (counter shows `500+`). Find-bar clicks do not close existing preview frames (`[data-preview-keep]` opt-out in `use-close-preview-frames`).
