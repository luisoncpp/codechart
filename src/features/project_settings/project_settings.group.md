Owns the Settings toolbar menu and editor configuration modal. Editor choices are
stored per project in `.codechart/config.json`; C++ projects also link to the
existing include-path modal. **Clear review info...** wipes all Review Notes and
all diff review checkmarks behind a confirmation modal.
