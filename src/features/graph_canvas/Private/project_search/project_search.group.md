The global find bar: debounced full-text search over module sources (Ctrl+Shift+F), local file-name filtering for Go to file (Ctrl+P), and local exported-symbol filtering for Go to symbol. All modes share match navigation that centers each hit via `focusOn`. Public surface is `index.ts` (`ProjectSearch`).
